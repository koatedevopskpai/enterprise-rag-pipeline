# IT Security Guidelines

These guidelines complement the Security Policy with day-to-day rules.

## Authentication

Multi-factor authentication is mandatory. Passwords must be at least 14
characters and are rotated only on suspicion of compromise.

## Incident reporting

Suspected security incidents must be reported to the security team within one
hour. Report phishing using the "Report Phishing" button.

## Data handling

Confidential and Restricted data may only be accessed from managed devices.
Sharing links to Confidential data must be restricted to named users.
