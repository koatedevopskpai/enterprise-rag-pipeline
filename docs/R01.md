# R01: fresh candidate gate — partial, Azure validation pending

The code path and offline contract tests are prepared. A real Azure baseline and
failure run remain pending the Azure track decision. No local result is Azure
validation, and R01 is not complete.

`fresh_quality.py` calls the application and Azure evaluators. It does not provision
resources. It writes an independent expectation manifest before inference, then
records generated answers, sources, scores, errors and recomputed means. Run UUID,
source revision, configuration/dataset/corpus hashes and case identities bind the
report to the candidate. `fresh_gate.py` checks those fields and a one-hour
freshness window. Missing/NaN/malformed scores, partial cases, evaluator failures
and altered means block. An offline-adapter report cannot pass a live gate.

Pilot Azure mean floors are relevance/groundedness >=4, coherence/fluency >=3 on
a 1-5 scale; any per-case score below2 is critical. These are provisional smoke
requirements, not production calibration or E04's different 0-1 custom rubric.

After a clean live dependency install and secure Azure configuration:

```powershell
python eval/fresh_quality.py --output-dir artifacts/R01-baseline --index-revision <fresh-index-id>
python eval/fresh_gate.py --report artifacts/R01-baseline/report.json --expected artifacts/R01-baseline/expected.json
python eval/fresh_quality.py --output-dir artifacts/R01-failure --index-revision <fresh-index-id> --fault-inject-unsupported-answer
python eval/fresh_gate.py --report artifacts/R01-failure/report.json --expected artifacts/R01-failure/expected.json
```

The explicit fault adapter changes application output and is recorded in config;
it is a controlled drill, not a production incident or another deployed commit.
Index revision is an operator assertion about freshly ingested content, not proof
of remote immutability. Input hashes establish identity, not truth or signatures.
The release system must independently supply its expected manifest and trust the
runner; metadata from an untrusted report alone is insufficient.
